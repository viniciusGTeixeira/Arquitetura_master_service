# Glossário
## Termos Técnicos do Projeto

---

| Termo         | Definição                                                                 |
|---------------|--------------------------------------------------------------------------|
| API           | Interface de Programação de Aplicações                                   |
| SSO           | Single Sign-On (autenticação única)                                      |
| JWT           | JSON Web Token, padrão de token de autenticação                          |
| Keycloak      | Solução open source para IAM e SSO                                       |
| Kafka         | Plataforma de mensageria distribuída                                   |
| Docker        | Plataforma de containers                                                 |
| Kubernetes    | Orquestrador de containers                                               |
| CI/CD         | Integração e entrega contínua                                            |
| LGPD          | Lei Geral de Proteção de Dados                                           |
| SLA           | Service Level Agreement (Acordo de Nível de Serviço)                     |
| SLO           | Service Level Objective (Meta de Nível de Serviço)                       |
| SLI           | Service Level Indicator (Indicador de Nível de Serviço)                  |
| DevOps        | Cultura de integração entre desenvolvimento e operações                  |
| PR            | Pull Request                                                             |
| MACH           | Arquitetura moderna baseada em Microservices, API-first, Cloud-native e Headless                                                     |
| PSR           | PHP Standards Recommendation                                             |
| E2E           | End-to-End (testes ponta a ponta)                                        |
| RBAC          | Role-Based Access Control (controle de acesso por papel)                 |
| OAuth2        | Protocolo de autorização para APIs                                       |
| OpenID Connect| Protocolo de autenticação federada                                       |

---

## Observações
- O glossário deve ser expandido conforme surgirem novos termos no projeto.
